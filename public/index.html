YOUR INFRASTRUCTURE

HTTPS protection.

Not checked yet.

The public endpoint is checked from this server, at most once per minute. A CDN may present a different certificate from your local gateway. Manage HTTPS from the server with sudo relaydesk https enable. Managed certificates renew automatically while the gateway runs.

Connected servers.

Connect 3x-ui using a dedicated API token. Tokens are encrypted on the server and never returned to this page.

Demo mode uses sample infrastructure. Run the installer to connect a real server.

Where do I get an API token?

In token-capable 3x-ui releases, open Panel Settings → API Tokens and create a dedicated token for Relaydesk. Copy it once into this form. If that section is missing, check your release: this adapter requires bearer authentication and the v2 inbound API. A successful probe checks read access; test a disposable client before relying on write compatibility.

Remove server?

Only servers without managed clients can be removed. This removes the saved connection and token; it does not uninstall 3x-ui.
